01 · 系統資料流

整套展示在一台 AWS EC2 執行。模擬電表持續更新數值，Gateway 主動採集；瀏覽器只查詢已入庫資料。

採集與平台各自設定

來源 meter-001 的四個點位，映射成平台「展示電表（site-001）」的感測點。Gateway 不負責平台資料命名。

中斷後保存與補送

Gateway 以 SQLite 保存待送資料；Broker 保留持久訂閱與待送狀態。兩者都有容量與保存限制，不代表主機故障時保證零遺失。

02 · CI/CD 自動部署

PR 只執行測試。main 更新且測試通過後，EC2 主動拉取可部署版本，GitHub 最後確認線上結果。

目前是單主機部署；更新期間可能短暫中斷，沒有跨主機容錯、零停機或資料庫自動回滾保證。
